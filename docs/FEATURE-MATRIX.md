# STM Feature Matrix

Source-grounded comparison of the **current RC4 candidate checkout (`1.4.0-rc.4`)**, based on `a3c2251` and inspected on 2026-10-09. The exact RC4 artifact is bounded-qualified below; detailed run evidence is linked from [RC Readiness](RC-READINESS.md). The prior exact RC3 candidates remain qualified only for their own immutable bytes below. "Implemented" describes code, not live qualification. V1 and V2 share memory utilities and configuration, not an identical runtime engine. Prior rc.2-versioned immutable-package acceptance is attributed separately below; it does not imply qualification of the current checkout, publication or qualification of every checkout variant.

## Generation

Sources: [V1 summarizers](../src/summarizer.ts), [V1 chunk lifecycle](../src/memory-lifecycle.ts), [V2 updater](../src/v2-memory-update.ts).

| Capability                | V1                                                                                                                                                                                                                                                        | V2 RC4 Candidate                                                                                                                                                                                                                                 |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Clean generation, default | Fresh temporary side session for each attempt; generated assistant response with summarizer system prompt and text.                                                                                                                                       | Standalone `context.generate.text({ prompt, model }, { signal })`; **no side session**.                                                                                                                                                          |
| Clean isolation           | Does not use main-session history/instructions; summarization is kept out of the main chat.                                                                                                                                                               | Direct text request contains the summarizer prompt, not main-session instructions/history as session context. Isolation does not mean a separate host session.                                                                                   |
| Active generation         | Generated prompt delivered into the active session, with summarizer system text; may appear in chat.                                                                                                                                                      | `context.session.generate({ sessionID, prompt }, { signal })`; session-bound, not clean-room generation.                                                                                                                                         |
| Inherited model           | Empty `memoryModel` omits the request override; a fresh clean side session therefore relies on host model resolution, while omission does not assure inheritance for an active invocation.                                                                | Clean explicitly passes the current input/history model; active uses session generation without a model argument.                                                                                                                                |
| Explicit `memoryModel`    | Valid `provider/model` passed in clean and active requests.                                                                                                                                                                                               | Valid override supported in clean only. Active plus override skips with `active_model_override_unsupported`; malformed nonempty override errors.                                                                                                 |
| Retries                   | `1 + sideSessionRetries` clean attempts; broadly retries caught clean failures, including timeout failures. Active has no equivalent retry loop.                                                                                                          | `1 + sideSessionRetries` attempts in clean **and active**, only for settled `V2TransientGenerationError` or malformed-output errors, within one chunk deadline. Arbitrary errors are not automatically transient.                                |
| Active fallback           | Opt-in after exhausted clean failures; retains configured model override.                                                                                                                                                                                 | Opt-in, at most one active fallback after settled retryable clean failures, only with no explicit override and time remaining.                                                                                                                   |
| Timeout/cancellation      | Clean prompt has a 90-second abort timer and best-effort server abort. No equivalent explicit deadline for active generation or temporary-session creation/deletion. Lifecycle invalidation blocks stale persistence, not necessarily ongoing generation. | Default 90-second **per-chunk** deadline shared by retries/fallback. Timeout/cancellation requests abort, prevents late-result persistence and does not retry/fallback. Host work may continue; generation reservation remains until settlement. |
| Output validation         | Assistant envelope, nonempty text, memory header and no raw template markers; normalized chunk also requires a section heading.                                                                                                                           | Nonempty text, memory header, all five required headings and no raw template markers before normalization. Validation is structural, not semantic correctness.                                                                                   |
| Cleanup                   | Best-effort immediate deletion, persisted `side-sessions.json` tracking and startup orphan scan.                                                                                                                                                          | No temporary sessions to clean. Disposal aborts plugin lifetime and unregisters hooks/tools/commands/RPC.                                                                                                                                        |

Both prompts treat existing memory and conversation as data, prioritize user instructions and conservatively retain prior facts. Model obedience, faithful retention and prompt-injection resistance are not guaranteed by these policies.

## Updates And History

Sources: [V1 runtime](../src/session-memory.ts), [collector](../src/message-collector.ts), [chunk lifecycle](../src/memory-lifecycle.ts), [V2 wiring](../src/index.ts), [idle scheduler](../src/v2-idle-update.ts), [durable history reader](../src/v2-current-history.ts), [updater](../src/v2-memory-update.ts).

| Capability             | V1                                                                                                                                      | V2 RC4 Candidate                                                                                                                                                                                                                                            |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Automatic updates      | Debounced `session.idle`, history bootstrap and pre-compaction refresh.                                                                 | Debounced execution succeeded/failed/interrupted events, plus context-hook catchup. Shutdown interruption invalidates rather than schedules. Independent of system-injection opt-in.                                                                        |
| Manual update          | Commands/tools attempt summarization, then return stored memory, not a structured success guarantee.                                    | Reads fresh settled durable visible text; returns outcome/reason and cumulative invocation progress. Read memory separately afterward.                                                                                                                      |
| Assistant gate         | No equivalent requirement that the delta contain an assistant reply.                                                                    | Delta must contain visible assistant text; otherwise skips. Task children never summarize; unavailable lineage metadata also skips.                                                                                                                         |
| Delta/checkpoint       | New visible messages after saved message-ID checkpoint; absent checkpoint falls back to available recent window.                        | New visible messages after checkpoint; missing checkpoint rebases to available visible input, still respecting any reset boundary.                                                                                                                          |
| Message limit          | `maxDeltaMessages` bounds recent history retrieval per update cycle.                                                                    | `maxDeltaMessages` bounds each chunk, not total history or total invocation.                                                                                                                                                                                |
| Input chunks           | Processes retained entries oldest-first within character target. Oversized single entry is truncated and checkpointed, losing its tail. | Processes delta in successive bounded chunks. Oversized entry is fragmented; checkpoint advances only after its final fragment. Earlier fragments can remain persisted without checkpoint.                                                                  |
| Input budget           | Conversation delta target, not entire prompt/model context/token budget.                                                                | Same distinction: existing memory, prompt scaffold and optional reference data add input beyond the conversation bound.                                                                                                                                     |
| Visible-text filtering | User/assistant text; excludes internal/thinking/tool/synthetic parts and memory self-injection.                                         | Context input accepts only nonsynthetic text; durable reader projects user/settled assistant text, excluding reasoning/tool outputs/system records. Excluded durable records retain IDs as reset anchors. Self-injection/internal summaries are filtered.   |
| Assistant bursts       | Optional last-consecutive-visible-assistant-reply collapse.                                                                             | Same optional collapse, applied after delta and assistant eligibility checks.                                                                                                                                                                               |
| `AGENTS.md`            | Optional sanitized project-root content, character-bounded, first chunk when no checkpoint.                                             | Optional bounded project-root reference data, not instructions; at most 20,000 bytes and configured input allowance, escaped in JSON, first chunk of eligible no-checkpoint update.                                                                         |
| Persistence/progress   | Atomic memory/checkpoint file replacements and guarded commits; restores previous memory on checkpoint failure where lifecycle permits. | Compare-and-replace memory writes; guarded rollback on checkpoint failure/cancellation. Reports checkpointed chunks/messages and uncheckpointed partial fragments; partial success can precede later error.                                                 |
| Busy work              | Per-session update exclusion with debounced pending replay.                                                                             | Shared in-process mutation/update ownership; busy callers do not queue updates. Idle scheduler allows a bounded replay. Main context callback skips both update and injection while updater ownership is busy.                                              |
| Pre-compaction         | Attempts bounded drain, refreshes if possible, then supplies stored memory even if still busy.                                          | Attempts settled durable-history refresh independently of injection gate. Opted-in injection uses stored memory on skipped/failed/busy refresh, bypasses cadence and does not wait for an existing update to drain.                                         |
| DCP `compress`         | Completed tool event triggers primary update and pending memory redelivery; children redeliver frozen memory, not summarize.            | **Not implemented:** no DCP-compress trigger. Native compaction is a separate capability.                                                                                                                                                                   |
| History snapshot       | SDK recent-history collection, bounded look-back.                                                                                       | Durable context and session/model reads are independent, **not an atomic model-facing snapshot**. Stops before unfinished assistant; manual update may process settled prefix, while idle/compaction refresh and command reset refuse unfinished snapshots. |

## Memory Consumption

Sources: [V1 runtime](../src/session-memory.ts), [tagged injection](../src/injection.ts), [V2 injection](../src/v2-context-injection.ts), [cadence](../src/v2-reminder-cadence.ts), [task-child snapshots](../src/v2-child-memory.ts), [reset actions](../src/v2-memory-tools.ts).

| Capability            | V1                                                                                                                                                                                       | V2 RC4 Candidate                                                                                                                                                                                                                                              |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pull memory           | `stm_memory_read` retrieves invoking session's stored file; creates template if absent. Agent chooses when to call.                                                                      | Same pull-first alternative; available with system injection disabled and without TUI. Pulling a child's own memory file is not the same as reading its frozen parent snapshot.                                                                               |
| Default injection     | Enabled when `enabled: true`: normal primary delivery uses `promptNoReply` at cadence.                                                                                                   | **All system injection disabled by default**, including primary, task-child and compaction injection. Set `enableLegacyPeriodicSystemTransform: true` to opt in; automatic updates remain independently enabled.                                              |
| Legacy transform flag | Switches primary periodic delivery from normal no-reply transport to legacy system-transform transport. Does not gate ordinary child or compaction injection.                            | Despite its historical name, gates all context/system memory injection. No V1-style no-reply delivery path.                                                                                                                                                   |
| Primary cadence       | Normal transport counts distinct visible user turns, every N; duplicate/revision delivery claims prevent repeated sends. Legacy transform counts hook turns using available message IDs. | Literally every N admitted user turns recorded by prompt hook and observed as users in context. Eligible turn remains eligible across tool continuations; existing tagged system memory is not duplicated.                                                    |
| Durable cadence       | Runtime counters/deduplication are process-local and bounded.                                                                                                                            | No reconstruction from historical user messages. Bounded process-local state (256 sessions, 4,096 tracked IDs per set/map); restart/eviction can restart counting.                                                                                            |
| Injection format      | Tagged compacted memory removes format/header/placeholder lines; character-clips memory payload.                                                                                         | Shared tagged format and compaction; same character clipping. Compaction hook bypasses primary cadence.                                                                                                                                                       |
| Subagents             | Parent snapshot captured at child creation in runtime metadata; children do not summarize. `injectInSubagents` controls child delivery. Startup/DCP/compaction use frozen snapshot.      | With both injection opt-in and `injectInSubagents`, task child freezes/persists parent snapshot on first eligible context read, **not creation-time capture or fork inheritance**. Later parent changes do not alter it. Lineage/snapshot errors fail closed. |
| Reset scope           | Clears memory/checkpoint and resets delivery state; no forward history boundary. Subsequent update may replay available history subject to look-back cap.                                | Clears memory/checkpoint and establishes persisted forward boundary. Updates process only post-anchor history; missing/duplicate anchor pauses update. Boundary resets cadence; child boundary suppresses frozen snapshot injection.                          |
| Reset anchor          | None.                                                                                                                                                                                    | Command anchors through last record of latest settled durable snapshot under mutation lock, not invocation message. Granular/legacy tool anchors at invoking message. Busy update or unsafe command snapshot refuses without mutation.                        |
| Erasure               | Does not erase conversation history.                                                                                                                                                     | Also not semantic erasure: later messages may reintroduce old facts. Multi-file reset is not crash-atomic; guarded rollback is not a database transaction.                                                                                                    |

## Configuration

All **17 `SessionMemoryConfig` fields** and actual shared defaults come from [memory utilities](../src/memory-utils.ts). Numeric settings are normalized to integers and clamped to the ranges shown; non-finite or otherwise unparseable numeric values fall back to defaults. These are implementation defaults, not guarantees about the installed rc.2 V2 behavior.

| Field                                 | Type / numeric range   | Default              | V1 behavior                                                                  | V2 RC4 Candidate behavior                                                                                           |
| ------------------------------------- | ---------------------- | -------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `enabled`                             | boolean                | `true`               | Gates automatic updates/delivery; diagnostic/manual controls remain exposed. | Gates summarization and system injection; tools/commands remain exposed.                                            |
| `memoryModel`                         | string                 | `""`                 | Inherit or valid override in both modes.                                     | Inherit; explicit override clean-only.                                                                              |
| `summarizerMode`                      | `"clean"` / `"active"` | `"clean"`            | Side session / active session.                                               | Standalone text / active session.                                                                                   |
| `cleanFallbackToActiveSession`        | boolean                | `false`              | Active fallback after exhausted clean failures.                              | One retryable-settled-failure fallback, no override, within deadline.                                               |
| `includeAgentsMdOnFirstUpdate`        | boolean                | `false`              | First no-checkpoint chunk reference.                                         | First eligible no-checkpoint chunk bounded reference.                                                               |
| `injectInSubagents`                   | boolean                | `true`               | Creation-time parent snapshot delivery.                                      | First-read task-child snapshot delivery, also requires injection opt-in.                                            |
| `enableLegacyPeriodicSystemTransform` | boolean                | `false`              | Primary transport selector; normal injection still enabled.                  | Opt-in gate for **all** system injection.                                                                           |
| `sideSessionRetries`                  | number, 0-10           | `1`                  | Additional clean attempts.                                                   | Additional settled retryable attempts in either mode; no side session.                                              |
| `remindEveryN`                        | number, 1-1,000        | `4`                  | Periodic primary delivery.                                                   | Opted-in primary admitted-turn cadence; not compaction/child cadence.                                               |
| `maxMemoryLength`                     | number, 200-50,000     | `10000`              | Normalization target and injection character clipping.                       | Same; snapshot bounds also use this value.                                                                          |
| `maxUpdateInputLength`                | number, 500-200,000    | `20000`              | Delta chunk character target; oversized entry truncated.                     | Delta chunk character target; oversized entry fragmented.                                                           |
| `debounceMs`                          | number, 100-120,000    | `1200`               | Idle scheduling and related duplicate/drain windows.                         | Native terminal-event idle scheduling.                                                                              |
| `debug`                               | boolean                | `false`              | Verbose events, including full summarizer prompt/injected memory.            | Generation/injection metadata without new prompt/response-body logging; operational details may still be sensitive. |
| `logMaxLines`                         | number, 20-20,000      | `300`                | Append log retention.                                                        | Same shared append log retention.                                                                                   |
| `maxDeltaMessages`                    | number, 20-10,000      | `200`                | Per-update recent-history look-back cap.                                     | Per-chunk entry cap.                                                                                                |
| `collapseAssistantBursts`             | boolean                | `false`              | Keep last consecutive visible assistant reply when enabled.                  | Same visible-delta policy.                                                                                          |
| `memoryDir`                           | string                 | `".opencode/memory"` | Memory/checkpoints/logs/side-session tracking.                               | Memory/checkpoints/logs/reset boundaries/task-child state.                                                          |

| Resolution/setup | Actual behavior                                                                                                                                                                                                                                                                                             |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Files            | `stm.jsonc` preferred over `stm.json` within each directory. Shared resolver finds nearest ancestor `.opencode` or uses base-directory `.opencode`.                                                                                                                                                         |
| Precedence       | Defaults, then global directories (`$XDG_CONFIG_HOME/opencode` or `~/.config/opencode`, then `~/.opencode`), then `$OPENCODE_CONFIG_DIR`, then project. Later sources override earlier keys.                                                                                                                |
| Reload           | V1 caches up to 60 seconds; V2 actions/hooks reread config. Restart after setup/config edits for predictable installed-host behavior.                                                                                                                                                                       |
| Storage paths    | Helpers join filenames to `memoryDir`; a relative value is resolved by filesystem operations against process working directory, not explicitly rebased to plugin location. Keep paths consistent across instances sharing sessions.                                                                         |
| Examples         | [Full example](../stm.example.jsonc) and the confirmed/generated smaller shared example both include `enableLegacyPeriodicSystemTransform: false`. The flag's V1 transport-selector versus V2 all-injection opt-in distinction is described above. Neither example is an exhaustive behavior specification. |

`maxMemoryLength` is **not a strict stored-file byte ceiling**: shared normalization keeps the line crossing its character target and adds the format marker. Injection payloads are character-clipped; prompt scaffold/format/preamble overhead is additional.
