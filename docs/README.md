# Documentation

These user guides describe the 1.4 feature set. Consult the
[changelog](../CHANGELOG.md) for available builds and release history; feature
documentation does not establish that a particular package has been published
or that every host/provider has been qualified.

## User guides

- [Project overview and quick start](../README.md)
- [Installation and configuration](CONFIGURATION.md): V1/V2 setup, paths,
  defaults, model selection and diagnostic privacy.
- [Memory generation](MEMORY-GENERATION.md): automatic/manual updates, modes,
  selected conversation, retries and size limits.
- [Memory delivery](MEMORY-DELIVERY.md): session messages, system/context
  reminders, cadence and compaction.
- [Commands and tools](COMMANDS.md): native menu, results, confirmations,
  status and connection limits.
- [Child sessions and compression](CHILD-SESSIONS.md): frozen parent snapshots,
  restart behavior and completed-compress integration.
- [Memory files and reset](MEMORY-FILES.md): local storage, forward reset
  boundaries, editing and cleanup.
- [Feature comparison](FEATURE-MATRIX.md) and [V1/V2 differences](FEATURE-PARITY.md)
